# Licences and data provenance

## Study data

The study data is generated locally by DuckDB's tpch extension
(`CALL dbgen`). Every output of this study is labelled "derived from
TPC-H". No result in this repository is an official TPC-H result, and no
result is comparable to official TPC results.

TPC-H tools not used; DuckDB tpch extension used instead. No TPC software
was downloaded, and no registration was made with the Transaction
Processing Performance Council or anywhere else for this study.

The synthetic late-arriving delta (data/gen/synth.py) is invented data,
labelled "synthetic, generated" in its own manifest. It is not TPC data
and not real customer data.

## Generated files

Data files under data/ and run outputs under outputs/ are build products,
regenerated by the Makefile. They are not committed to this repository.
The committed evidence is the generated results under results/, which the
scripts produce from the run logs and checksum records.
